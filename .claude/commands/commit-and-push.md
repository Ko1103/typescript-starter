変更をコミットしてプッシュしてください。以下の手順を順番に実行してください。

## 引数

$ARGUMENTS がコミットメッセージです。空の場合は変更内容から適切なコミットメッセージを生成してください。

## 手順

### 1. 状態確認

- `git status` で現在のブランチと変更ファイルを確認する
- `git diff` でステージ済み・未ステージの差分を確認する

### 2. ブランチ作成（mainの場合のみ）

- 現在のブランチが `main` の場合、変更内容に基づいた適切なブランチ名で新しいブランチを作成してcheckoutする
- ブランチ名は `feature/短い英語の説明` の形式にする
- `main` 以外のブランチにいる場合はそのまま続行する

### 3. コミットとプッシュ

1. 変更ファイルを `git add` する（機密ファイルに注意する）
2. コミットメッセージを付けて `git commit` する
3. pre-commitフックでlintエラーが出た場合:
   - エラー内容を確認し、該当ファイルを修正する
   - `npm run fix` で自動修正を試みる
   - 自動修正できないものは手動で修正する
   - 再度 `git add` して `git commit` する
   - エラーが解消するまで繰り返す
4. コミットが成功したら `git push -u origin <ブランチ名>` でプッシュする

### 4. Pull Request作成

1. `gh pr list --head <ブランチ名>` で現在のブランチにPull Requestが既に存在するか確認する
2. Pull Requestが存在しない場合、`gh pr create` で `main` ブランチに向けてPull Requestを作成する
   - タイトルはコミットメッセージまたは変更内容から適切に設定する
   - 本文には変更内容の要約を含める
3. Pull Requestが既に存在する場合は、そのURLを表示して終了する
